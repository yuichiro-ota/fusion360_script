# ロボット用 Fusion 360 パラメトリック部品ジェネレータ

14 本のスクリプトで、ロボットアームに使う機械部品・機構をほぼ網羅します。
すべて **ダイアログでパラメータを入力するだけ** で部品が生成されます。

スクリプトは 3 系統あります。

- **単機能スクリプト**(`GearSpurHelical` など 10 本) — 部品ごとに 1 スクリプト。目的の部品が決まっているとき。
- **統合スクリプト**(`RobotArmParts` / `RobotDriveParts` / `RobotLinkages` の 3 本) — 1 つのダイアログで部品種別を選ぶ。ざっと試すとき。
- **機構一式スクリプト**(`RobotDiffJoint` の 1 本) — 関節ユニットを構成部品まるごと生成する。

機能は重複します(例: 平歯車は `GearSpurHelical` と `RobotArmParts` の両方にある)。どちらを使っても構いません。

---

## インストール

各スクリプトは **フォルダ名 = ファイル名** のフォルダごと配置します(`.py` と `.manifest` の 2 ファイル)。

Fusion 360 で:

1. 「ユーティリティ」タブ → 「アドイン」 → 「スクリプトとアドイン」
2. 「スクリプト」タブの **「+」** を押し、使いたいスクリプトのフォルダを指定
3. 一覧から選んで **「実行」**

---

## ドキュメントの種類について(重要)

Fusion の **「パーツ」ドキュメントは 1 コンポーネントしか持てません。**
そのままだと複数部品を作るスクリプトは
`パーツ デザイン ドキュメントには 1 つのコンポーネントのみを含めることができます`
というエラーで失敗します。

そのため各スクリプトはドキュメント種別を自動判定し、次のように動作します。

| ドキュメント | 生成のされ方 |
|---|---|
| **アセンブリ** (推奨) | 部品ごとに**別コンポーネント**を作り、組立位置に配置 |
| **パーツ** | 1 つのルート コンポーネント内の**別ボディ**として生成し、組立位置に配置 |

パーツ ドキュメントで実行した場合は、生成完了メッセージにその旨が表示されます。
結合・切り取りは自分の部品のボディだけを対象にするので、隣の部品が削れることはありません。

**ジョイントを付けて動かしたい場合はアセンブリ ドキュメントで実行してください。**
(ボディのままでも、右クリック →「ボディからコンポーネントを作成」で後から分割できます)

### 減速比のめやす

- **サイクロイド減速機**: 減速比 = ピン数 − 1(入力=偏心カム / 出力=フランジ / ハウジング固定)
- **ハーモニックドライブ**: 減速比 = FS歯数 ÷ 2(CS歯数 = FS歯数 + 2)
- **遊星歯車**(リング固定・キャリア出力): 減速比 = 1 + リング歯数 ÷ 太陽歯数
  等配置条件 `(太陽歯数 + リング歯数) % 遊星数 == 0` はスクリプトが自動チェックします
- **ウォームギア**: 減速比 = ホイール歯数 ÷ 条数。進み角 約5°以下でセルフロック

## 統合スクリプト

### `RobotArmParts` — 基本要素

| 部品 | 主なパラメータ |
|---|---|
| 平歯車(インボリュート) | モジュール / 歯数 / 圧力角 / 歯幅 / 軸穴径 |
| ベベルギア(すぐばかさ歯車・軸角90°) | モジュール / 歯数 / **相手歯数** / 圧力角 / 歯幅 / 軸穴径 |
| タイミングプーリ(GT2近似) | 歯数 / ベルトピッチ / 幅 / 軸穴径 / フランジ有無 |
| 深溝ボールベアリング | 外径 / 内径 / 幅 / ボール数 |

**差動(ディファレンシャル)の作り方**: ベベルギアでサイドギア2個 + ピニオン2個を生成し、
軸角90°で十字に配置。1:1差動なら全て同歯数(相手歯数 = 自歯数、円錐角45°)。

### `RobotLinkages` — リンク機構

| 機構 | 主なパラメータ |
|---|---|
| テオ・ヤンセン機構 | 倍率(標準 Holy Numbers 内蔵) / クランク角 |
| ヘッケンリンク | 基準長 a / クランク角(直線区間 90〜270°) |
| チェビシェフリンク | 基準長 a / 入力角(有効 約40〜100°) |
| 平行リンク(膝) | リンク長 / ピボット間隔 / 膝振り角 / すね長さ |

各リンクは**ピン穴付きの丸端バー**として Z 方向に積層生成。
そのまま切削/プリントするか、回転ジョイントで組んでモーションスタディへ。

### `RobotDriveParts` — 駆動系

| 部品 | ポイント |
|---|---|
| **サイクロイド減速機** | 減速比 = ピン数 − 1。ディスク・ピンリング・偏心軸・出力キャリアを一式生成 |
| **遊星歯車機構** | 太陽 + 遊星 + 内歯リング + キャリア。等配置条件を自動チェック |
| はすば / ヘリンボーン歯車 | ねじれ角指定。ヘリンボーンは上下逆ねじれで自動生成 |
| ウォームギア | 進み角を自動計算(約5°以下でセルフロック)。多条対応 |
| ラック & ピニオン | 1回転あたりの送り量を表示 |
| カム & フォロワ | サイクロイド運動曲線(加速度連続)。ピッチ曲線を**法線方向に**オフセットした実輪郭。最大圧力角とアンダーカットを自動チェック。基礎円半径 = カム輪郭の最小半径(ローラー中心は 基礎円+ローラー半径 の位置) |
| 自在継手 | ヨーク×2 + クロス。等速にするならダブルカルダン |

## 機構一式スクリプト

### `RobotDiffJoint` — ベルト駆動 差動2自由度関節

ベベルギア差動による**ピッチ + ロールの2自由度関節**(手首・肩)を、
モータ2個ぶんの駆動系まで含めて一式生成します。

| 生成される部品 | 内容 |
|---|---|
| サイドギア ×2 | 左右の入力ベベル。**入力軸と一体**(軸受 → ヨーク旋回ボス → フレーム板 → 大プーリ を貫通) |
| 出力ベベル ×1 | ロール軸の出力。ハブ上端がフランジ下面で止まり、締結用のねじ穴つき |
| 関節プーリ ×2 / モータプーリ ×2 | GT2 近似。ベルト減速比 i = 関節歯数 ÷ モータ歯数。フレーム板の外で同一面に並ぶ |
| ヨーク(差動キャリア) | ピッチ軸まわりに旋回。旋回ボスはフレーム板を貫通。軸受座・軽量化窓つき |
| 出力フランジ | 出力ベベルのハブ上端にボルト止め |
| フレーム側板 ×2 | ヨーク旋回軸受座 + モータ取付(ベルトテンション用の長穴つき) |
| モータ外形 ×2(任意) | 参考用。位置と干渉の確認に使う(印刷対象ではない) |

モータはフレーム板の**外面にスペーサを挟んで**固定し、軸は内向き。プーリはモータ前面と
板の間に入り、関節プーリと同一面に並びます。必要なスペーサ長と軸の突き出し量は
生成完了メッセージに表示されます。

**運動学**(θ1, θ2 = 左右モータ角、Zs = サイドギア歯数、Zo = 出力ベベル歯数)

- ピッチ φ = (θ1 + θ2) / 2i  … **両モータ同方向**
- ロール ψ = (Zs / Zo) × (θ1 − θ2) / 2i  … **両モータ逆方向**

逆解も含めて生成完了メッセージに表示されます。ベルト長は必要長を計算し、
近い標準在庫長3件とその時の軸間距離を提示します。

主なパラメータ: ベベルのモジュール / サイドギア歯数 Zs / 出力ベベル歯数 Zo / 歯幅 /
関節・モータのプーリ歯数 / 軸間距離 / 3種の軸受寸法(入力・ヨーク旋回・出力) /
ヨーク板厚・幅 / フレーム板厚 / モータ(NEMA17・14・23)

> Zs と Zo の歯数比が極端(片方が数倍)だと歯元が隣の歯とくっつきます。
> 1:1(Zs = Zo、円錐角45°)を基準に、比を付けても 2 倍程度までを推奨。

## 組み合わせの例(6軸アーム)

| 関節 | 推奨 |
|---|---|
| ベース旋回(J1) | サイクロイド減速機(1:20〜1:40) |
| 肩・肘(J2/J3) | 遊星歯車 or ウォーム(セルフロック = 電源断でも落ちない)+ 平行リンク |
| 手首(J4〜J6) | `RobotDiffJoint` の差動2自由度関節(モータ2個でピッチ+ロール。モータを根元に置けて先端が軽い) |
| グリッパ | ラック&ピニオン(平行開閉)or 平行リンク |

モータマウント・軸受ハウジング・シャフト等の実装部品は生成スクリプトを用意していません（今後実装予定）

## 注意事項

- **歯形は近似です。** 生成後に Fusion の「干渉」コマンドでかみ合いを確認し、
  必要ならバックラッシュ欄で歯厚を調整してください。
- 3Dプリントの目安すきま: 歯車バックラッシュ 0.1〜0.2mm、圧入 0〜−0.1mm、
  すべり嵌合 0.2〜0.4mm。
- 内部単位は cm / rad ですが、**ダイアログの入力はすべて mm / deg** です。
- 生成後もタイムラインの各フィーチャを編集すれば寸法変更できます。
- ハーモニックドライブのフレクスプラインは**無変形状態**で生成されます。実動作には
  薄肉壁の弾性変形が必要なため、TPU 等の柔軟材や壁厚の調整を検討してください。
